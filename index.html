A small core, optional capabilities

Every capability is an opt-in file. A store locator loads the core and the UI add-on; a full basemap adds the vector renderer. You only ship what you use.

Raster slippy map

Drag, pinch, wheel, keyboard, inertia, bearing and pitch, bounds, zoom snapping and a context menu in the raster core.

Vector tiles

A typed-array MVT decoder in a Web Worker, per-tile style buckets and cached Path2D geometry on Canvas 2D.

MapLibre Style v8 subset

Load selected style.json layers and expressions, with filters, zoom functions, symbol placement and MapLibre zoom semantics.

Building extrusions

fill-extrusion features with cross-tile depth sorting, lighting and picking, drawn with the affine camera.

Markers, popups & controls

MapLibre- and Leaflet-shaped markers, popups and tooltips, plus navigation, scale, geolocation and attribution controls.

GeoJSON & overlays

Dynamic routes, tracks and areas; optional field annotations; extra XYZ/WMS and aerial imagery.

Camera animations

flyTo, easeTo, jumpTo and fitBounds with padding, respecting prefers-reduced-motion.

Queries & layer events

queryRenderedFeatures, click/mouseenter per layer and cursor handling, in MapLibre's event shapes.

Interaction and resource limits

Keyboard and screen-reader support, bounded caches, navigation-aware tile preloading and a device-pixel-ratio cap.

Choose the renderer that fits

        
All three projects use permissive code licenses. Map tiles and imagery have separate terms. This page bundles only MicroMap code.

        

          
MicroMap · MIT
A small raster core with optional Canvas vector tiles and GeoJSON. Rotation and affine pitch suit controlled map views; there is no perspective horizon or terrain.

          
Leaflet · BSD-2-Clause
A mature 2D map library with raster tiles, GeoJSON, markers and a broad plugin ecosystem. Vector-tile rendering uses plugins.

          
MapLibre GL JS · BSD-3-Clause
A WebGL renderer for vector maps, broad style support, perspective camera, terrain and globe. It is a stronger fit for demanding 3D and style-heavy maps.

        

        
License texts: MicroMap, Leaflet and MapLibre GL JS. Map data and imagery follow their own terms.
