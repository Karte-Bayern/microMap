MapLibre-compatible map

Public MapLibre styles rendered by microMap's new Map(). Right-drag or Ctrl-drag to rotate and tilt; click a feature to inspect it.

The code 
const map = new microMap.Map({
  container: 'map',
  style: 'https://tiles.openfreemap.org/styles/liberty',
  center: [11.576, 48.137], zoom: 15, pitch: 60
});
map.addControl(new microMap.NavigationControl());
map.on('click', event => {
  const features = map.queryRenderedFeatures(event.point);
  new microMap.Popup().setLngLat(event.lngLat)
    .setText(features.map(f => f.layer.id).join(', '))
    .addTo(map);
});
